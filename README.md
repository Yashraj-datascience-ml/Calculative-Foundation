# 📊 Calculative Foundation – Linear Algebra with Python

A Practical Data Science Project Demonstrating Linear Algebra Concepts Through Student Academic Performance Analysis.

---

## 📌 Project Overview

**Calculative Foundation** is a Python-based academic project focused on understanding and implementing fundamental concepts of Linear Algebra using a Student Academic Performance Dataset.

The project demonstrates how mathematical concepts such as vectors, matrices, linear transformations, geometric representations, eigenvalues, and eigenvectors can be applied to multidimensional data.

The analysis is performed using Python in Jupyter Notebook, supported by numerical computations and graphical visualizations.

## 🎯 Project Objectives

- Understand the practical applications of Linear Algebra.
- Represent student academic scores using vectors and matrices.
- Perform vector and matrix operations using NumPy.
- Explore geometric concepts such as lines, planes, and hyperplanes.
- Apply dimensionality reduction using PCA.
- Calculate and interpret eigenvalues and eigenvectors.
- Visualize mathematical concepts through Python graphs.

## 📂 Dataset Information

This project uses a **synthetic Student Academic Performance Dataset** containing academic scores for 100 students across five subjects.

**Dataset Features:**

| Column | Description |
|---|---|
| Student_ID | Unique student identifier |
| Mathematics | Mathematics score |
| Physics | Physics score |
| Chemistry | Chemistry score |
| Biology | Biology score |
| English | English score |

**Dataset Details:**
- Total Students: 100
- Total Subjects: 5
- Total Columns: 6
- Missing Values: 0

*Note: This dataset is synthetically generated for educational and analytical purposes. It does not contain actual student records.*

## 📚 Project Implementation

### Part A – Vector Operations

Implemented fundamental vector operations using student subject scores.

- Vector Representation
- L1 Norm (Manhattan Norm)
- L2 Norm (Euclidean Norm)
- Dot Product
- Angle Between Two Vectors
- Cross Product
- Vector Projection

### Part B – Matrix Operations

Created and analyzed student performance matrices.

- Matrix Representation
- Matrix Addition
- Matrix Multiplication
- Matrix Transpose
- Determinant Calculation
- Matrix Inverse (where possible)

### Part C – Linear Transformations & Geometry

Explored geometric representations of multidimensional student data.

- 2D Line Visualization
- 3D Plane Visualization
- Hyperplane Representation
- Dimensionality Exploration (2D, 3D and 5D)
- PCA-based 5D to 3D Projection

### Part D – Eigenvalues & Decomposition

Applied eigenvalue decomposition to understand the covariance structure of the dataset.

- Covariance Matrix Calculation
- Eigenvalues
- Eigenvectors
- Explained Variance
- Eigenvalue Decomposition
- Scree Plot Visualization
- Reconstruction Verification

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the Repository**

```bash
git clone https://github.com/Yashraj-datascience-ml/Calculative-Foundation.git
```

**2. Navigate to the Project Directory**

```bash
cd Calculative-Foundation
```

**3. Install Required Libraries**

```bash
pip install numpy pandas matplotlib seaborn jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

**5. Open the Notebook**

Open `Calculative_Foundation_Analysis.ipynb` and run the notebook cells sequentially.
